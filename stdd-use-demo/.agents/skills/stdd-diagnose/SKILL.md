# 缺陷诊断与回归准备

1. 从任务已授权的工单、日志、截图和本地代码收集证据。记录最小必要环境和复现数据，证据引用使用脱敏片段或原系统链接。
2. 对照现行规格定位预期和实际结果。给出可重复步骤、受影响版本与最接近的稳定测试入口。记录已经观察到的事实及仍需验证的根因假设。
3. 使用 `docs/stdd/templates/diagnosis.md` 记录诊断，可以合入现有工单。将能区分错误行为与正确行为的样例写成或关联一个 `AC-*`。
4. 已授权修复时，从回归用例开始执行 `stdd-delivery`；仅排查时交付复现证据和待确认项。
