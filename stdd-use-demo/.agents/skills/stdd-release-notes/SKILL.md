# 版本差异与发布说明

1. 从任务或发布记录定位起止版本。限定到两次已知提交或标签时，用 `python3 -B scripts/git_range.py <基准引用> <候选引用>`。按日期汇总时采用项目迭代日历和可核对的合入记录，注明分支、时间窗和时区。
2. 对照候选差异、已合入的变更记录、规格和验收证据。将相关提交合并到可观察的变更条目，检查已撤回的提交和候选版本中仍然存在的效果。
3. 依据 `docs/stdd/templates/release.md` 起草说明，注明版本范围、用户影响、兼容与迁移、验收状态和待处理项。区分候选范围、实际验收和已发布状态，草稿中的发布状态由真实记录支持。
