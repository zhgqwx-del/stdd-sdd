# 生成验收记录

1. 读变更范围、确认后的规格和已有 `verification.md`，将每个受影响的 AC 映射到可执行检查、手工步骤或待验证项。
2. 按仓库命令运行定向测试和适用的完整检查。记录实际命令、退出状态、环境、数据、受测 SHA 或工作区状态。检查失败时保留相关断言和证据，能够继续的其他检查照常记录。
3. 按 `docs/stdd/templates/verification.md` 更新变更自身的 `verification.md`。已有历史证据仍可链接。未执行的手工检查填写预期、执行步骤及待验证状态，观察结果由实际执行的人或浏览器验证填入。
4. 回报通过、失败和待验证的场景 ID。测试报告由本次结果填写，实际修复作为对应实现任务处理。
