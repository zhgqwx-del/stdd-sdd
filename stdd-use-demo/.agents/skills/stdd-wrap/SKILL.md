# 开发收尾与交接

1. 确认变更目录和当前受测状态，核对 `tasks.md`、规范及验收记录。需要补跑时用项目命令验证未覆盖的部分，并按 `stdd-test-report` 的验收字段留证。
2. 同步已经确认且实际实现的行为与契约。长效架构决策归 ADR，已验证的通用工程约定回写工程文档。暂缓事项记录负责人及复跑方式。
3. 为下一次会话留下当前提交或工作区状态、复跑指令、阻塞和下一步。在准备合并时按项目约定归档变更，核对归档后的相对链接。
4. 按 `.github/pull_request_template.md` 准备 PR 内容，关联规格、证据、影响和按需提供的撤回方式。提交整理及远程操作按当前任务授权和项目的 Git 流程进行。
