# 将免运费门槛调整到 129 元规格

本规格记录本次教学变更的验收口径。

## 目标

> 结算时按商品小计报价。满 129 元免运费，低于门槛收 8 元。继续使用整数分并拒绝无效输入。

## 需求

### REQ-SHIP-001

商品小计低于 12,900 分，运费为 800 分。商品小计达到或超过 12,900 分，运费为 0 分。

### REQ-SHIP-002

商品小计须为非负的 Python 内置 `int`。负数、浮点数、字符串、布尔值和空值仍抛出 `ValueError`。

## 验收场景

### AC-SHIP-001

关联 [REQ-SHIP-001](#req-ship-001)。小计为 0、9,900 或 12,899 分时，请求报价应返回 800 分。其中 9,900 分是旧门槛。

### AC-SHIP-002

关联 [REQ-SHIP-001](#req-ship-001)。小计恰好为 12,900 分时，请求报价应返回 0 分。

### AC-SHIP-003

关联 [REQ-SHIP-001](#req-ship-001)。小计为 12,901 分时，请求报价应返回 0 分。

### AC-SHIP-004

关联 [REQ-SHIP-002](#req-ship-002)。小计为 `-1`、`12900.0`、`"12900"`、`True` 或 `None` 时，请求报价应抛出 `ValueError`。
