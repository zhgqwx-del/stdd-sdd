# 将免运费门槛调整到 129 元验收计划

## 验证范围

从公开报价函数验证[变更规格](spec.md)，保留旧输入验证的回归检查。

## 用例和入口

| 场景 ID | 测试层或方式 | 初始数据与操作 | 预期与证据出口 |
| --- | --- | --- | --- |
| `AC-SHIP-001` | 自动化 | 分别传入 `0`、`9900`、`12899` | 返回 `800` |
| `AC-SHIP-002` | 自动化 | 传入 `12900` | 返回 `0` |
| `AC-SHIP-003` | 自动化 | 传入 `12901` | 返回 `0` |
| `AC-SHIP-004` | 自动化 | 传入负数、浮点数、字符串、布尔值和空值 | 抛出 `ValueError` |

## 环境和风险

使用 Python 标准库 `unittest`，从项目根目录运行 `make test-acceptance`。先在原有实现上运行新用例，再改实现并运行 `make check`。将观察结果写入[验收记录](verification.md)。
