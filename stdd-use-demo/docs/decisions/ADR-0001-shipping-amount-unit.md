# ADR-0001 运费报价使用整数分

- 状态 已采纳（演练现行契约）
- 关联讨论 [运费报价的金额单位](../discussions/shipping-amount-unit.md)
- 关联变更 [将免运费门槛调整到 129 元](../../changes/archive/002-free-shipping-threshold/change.md)

## 背景

结算要精确比较免邮门槛，调用方和验收用例需要共享金额表示。

## 决策

运费报价接受非负整数分，并返回整数分，按[现行规格](../../specs/shipping/spec.md)处理无效输入。展示层可将结果换算成元。整数分便于直接验证门槛前后一分的行为。

## 后果与复查条件

后续运费变更保持此接口约定。新增币种或需要小于一分的精度时重新评审。
