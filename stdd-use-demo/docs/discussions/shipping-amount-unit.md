# 运费报价的金额单位

- 状态 已结论（演练记录）
- 关联变更 [将免运费门槛调整到 129 元](../../changes/archive/002-free-shipping-threshold/change.md)

## 待决定的问题

产品按元描述和展示门槛，研发和测试需要统一接口输入、输出和比较的单位。这个约定也适用于后续运费规则。

## 选项与证据

- 接口接收和返回整数分时，计算门槛和测试边界可以直接用整数表达。展示层仍可换算为元。
- 接口使用以元为单位的小数时，调用方和测试还需统一精度和舍入方式。现有报价函数、规格与验收已经使用整数分。

## 结论与后续

沿用现行金额契约，门槛 129 元在接口中为 12,900 分。长期约定见 [ADR-0001](../decisions/ADR-0001-shipping-amount-unit.md)。
